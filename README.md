## 📋 О проекте

**МенеджерЗадач** — это элегантное одностраничное веб-приложение, разработанное для эффективного управления личными задачами и заметками. Приложение предоставляет современный и интуитивно понятный интерфейс, который помогает пользователям организовать свою жизнь легко и красиво.



## ✨ Ключевые особенности

- **👁️ Современный темный интерфейс** — приятный для глаз дизайн с темной цветовой схемой
- **💾 Автономная работа** — все данные хранятся в локальном хранилище браузера (localStorage)
- **📱 Адаптивный дизайн** — корректное отображение на любых устройствах (ПК, планшеты, смартфоны)
- **🔍 Продвинутый поиск** — мгновенный поиск по задачам и заметкам
- **📅 Интегрированный календарь** — визуализация задач в календарном формате

## 🛠️ Технологии

Приложение разработано исключительно с использованием:

- **JavaScript (ES6+)** — нативные возможности JavaScript без внешних фреймворков
- **HTML5** — современная семантическая разметка
- **CSS3** — продвинутые стили с использованием CSS переменных и гибкой сетки
- **LocalStorage API** — для хранения пользовательских данных в браузере

## 📌 Функциональность

### Управление задачами

- Создание, редактирование и удаление задач
- Установка приоритетов (низкий, средний, высокий)
- Назначение сроков выполнения
- Отметка о выполнении задач
- Сортировка и фильтрация по различным параметрам

### Управление заметками

- Создание, редактирование и удаление заметок
- Форматирование текста
- Изменение цвета заметки
- Сортировка заметок по дате создания или заголовку

### Календарь задач

- Визуализация задач в календаре
- Быстрое создание новых задач из календаря
- Визуальное отображение дней с запланированными задачами
- Навигация по месяцам

### Дополнительные возможности

- Поиск по всем задачам и заметкам
- Фильтрация по статусу и приоритету
- Интуитивно понятные модальные окна для редактирования
- Отзывчивый интерфейс с визуальной обратной связью

## 🚀 Начало работы

1. **Открыть приложение** — просто откройте файл `index.html` в любом современном браузере

2. **Создание задачи:**
   - Перейдите на вкладку "Задачи"
   - Нажмите кнопку "Новая задача"
   - Заполните необходимую информацию
   - Нажмите "Сохранить"

3. **Создание заметки:**
   - Перейдите на вкладку "Заметки"
   - Нажмите кнопку "Новая заметка"
   - Введите заголовок и содержание
   - Выберите цвет (опционально)
   - Нажмите "Сохранить"

4. **Работа с календарем:**
   - Перейдите на вкладку "Календарь"
   - Просматривайте задачи по дням
   - Выберите дату для создания новой задачи

- Вы полностью контролируете свою информацию

## 👨‍💻 Разработка

Проект построен с использованием модульной архитектуры:
- `app.js` — инициализация приложения и основная логика
- `tasks.js` — функционал управления задачами
- `notes.js` — функционал управления заметками
- `calendar.js` — функционал календаря
- `utils.js` — вспомогательные утилиты и функции
